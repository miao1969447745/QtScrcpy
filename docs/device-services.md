# 设备列表中的投屏服务

“服务”指本程序为某台手机建立的 scrcpy 投屏/控制会话，不是 ADB 服务、无线调试或 sndcpy 音频。

- 设备列表显示“设备名称｜服务状态｜操作”，序列号在设备名称的悬浮提示中。
- “启动服务”和双击设备名称走同一条启动流程，使用当前投屏配置。不同设备的会话相互独立。
- 未启动或启动失败：仅“启动服务”可用。
- 正在启动：禁止重复启动；“停止服务”可取消正在启动的会话。
- 已启动：仅“停止服务”可用。
- 正在停止：两个按钮均不可用。停止或设备断开后恢复可启动状态；离线设备不能启动。
- 只有收到该设备的连接成功事件才显示“已启动”，不是一点击就显示成功。状态只代表本程序的会话，不扫描其他程序启动的 scrcpy。
- 点击某一行的操作只针对该行的序列号，不依赖下方选中的设备，也不依赖刷新后的行号。
- “全部停止服务”保留，结束所有投屏会话，并取消尚未完成的启动检查。停止不关闭手机、不关闭无线调试、不清除手机业务数据。

列表自动刷新和设备重命名不会丢失服务状态；已存在会话的设备暂时不在 ADB 列表中时仍保留行，以便停止会话。

验证：Windows Qt 6 Release 编译、离线设备列表控件测试（无真实手机输入）、核心会话取消后重启测试均通过。取消测试在启动的零定时器执行前销毁会话，不调用 ADB、不操作真实手机。真实手机投屏操作和完整窗口视觉排版仍需使用者验收。
