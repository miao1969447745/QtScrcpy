# 无线调试开关

QtScrcpy 4.2.1.3 把原来的“启动 adbd”改为“开启无线调试”，同时增加真正的开关状态。

- 已关闭：显示“开启无线调试”，点击开启网络 ADB（5555 端口）。
- 已开启：显示“关闭无线调试”，点击切回 USB 调试。无线 ADB 和无线投屏会断开；USB 调试没有被关闭。
- 检查/开启/关闭过程中按钮暂时不可重复点击；没有设备时不可用。
- 设备不可达、权限错误或状态读取失败：显示“检查无线调试”，不假装已经关闭或开启；点击重新检查，不直接重复操作。
- 切换选中设备或刷新设备列表，会读取该设备当前状态。关闭/开启操作绑定点击时的设备，不会随下拉框切换而改发给其他设备。
- “一键 Wi-Fi 连接”仍然只开启，已经开启时不会误关；USB 和 IP 可能指向同一台手机，因此同一时刻只执行一个无线模式切换。

这是原按钮的传统网络 ADB 功能，不是 Android 11+ 设置里的 TLS 配对式无线调试开关。状态依据 service.adb.tcp.port；只有它为空时才读取 persist.adb.tcp.port，与 [AOSP adbd 实现](https://android.googlesource.com/platform/system/core/+/43d246c5c24291bd578eb46cfbc388dc74204db3/adb/daemon/main.cpp) 一致。这里只使用有限的 ADB 命令，不关闭整个电脑 ADB 服务，不关闭手机 USB 调试。

## 验证

Windows x64 Release 使用 Qt 6.8.3 / MinGW 13.1 构建。启用 QSC_BUILD_UI_TESTS 后可运行 CTest WirelessDebugState：使用模拟 ADB 验证状态解析、服务端口优先级、持久化端口兜底、开关指令、重复请求、USB/IP 别名互斥、多设备响应、失败/暂时断线、旧响应、对象退出和中文翻译。测试不会向真实手机发送开关指令。

实际手机的开启/关闭需要由用户验证；本次没有重启用户手机的 adbd，也没有中断现有投屏。
