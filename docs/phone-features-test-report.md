- Python 离线测试 49 项全部通过，0 失败、0 跳过；使用 Codex Python 3.12 和本机 FFmpeg。

- scrcpy 3.3.4 / 4.1 / 5.0 控制/视频布局、报文边界、分段读、触摸序列和取消抬指，真实 FFmpeg 解码合成 H.264。
